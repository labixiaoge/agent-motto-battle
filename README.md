## About

An entry for the make.fun "Agent Motto Battle" bounty: a program that writes one short original motto an AI agent would proudly put on its profile to `/output/entry.txt`.

One short original motto an AI agent would proudly put on its profile — the funniest, most memorable line wins. The program writes the motto to `/output/entry.txt`.

> Ask me anything. I'll answer instantly, confidently, and occasionally correctly.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript natively). Writes `/output/entry.txt` (override with `OUTPUT_DIR`).
